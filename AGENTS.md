# Confirma SUS

Projeto interno para automação de convocações SUS por WhatsApp.

## Regras

- Este checkout no HD PROJETOS é a fonte oficial do código.
- Preserve a separação entre aplicações e pacotes do monorepo.
- Nunca registre tokens, senhas ou dados reais de pacientes no repositório.
- Envios reais dependem de autorização operacional e configuração segura; use `DRY_RUN` por padrão.
- Não faça commit, push, publicação ou implantação sem pedido explícito.
- Documente mudanças funcionais no README ou em `docs/`.
